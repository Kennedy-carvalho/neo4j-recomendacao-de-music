= Dados do projeto musical

== Arquivos

`music_info.csv` contem metadados de faixas, artista, tags, genero, ano e caracteristicas de audio.

`listening_history.csv` contem `track_id`, `user_id` e `playcount`. O arquivo completo tem cerca de 603 MB e fica no ambiente local; ele e ignorado pelo Git para evitar falha no envio ao GitHub.

`samples/listening_history_sample.csv` e uma amostra menor para validar a importacao e o modelo. Use-a com `music_info.csv` para testes rapidos.

== Chave de integracao

`track_id` e a chave entre os arquivos. O script de historico cria um no `Track` com esse identificador mesmo quando nao ha metadados correspondentes; essas faixas nao aparecem nas consultas que exigem um nome.
